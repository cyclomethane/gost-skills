# gost-skills — скилл ИИ-агента для оформления документов по ГОСТ

Один скилл для ИИ-агентов (ZCode, Claude Code и любые ассистенты, читающие
`.agents/skills/`): собери документ по ГОСТ или пришли готовый — скилл вернёт
список замечаний со ссылкой на пункт стандарта для каждого.

[`skills/gost`](skills/gost/) покрывает диссертации и авторефераты (ГОСТ Р
7.0.11-2011), ВКР, дипломы, курсовые и отчёты по практике, отчёты о НИР (ГОСТ
7.32-2017), журнальные статьи (ГОСТ Р 7.0.7-2021), рефераты и аннотации (ГОСТ
Р 7.0.99-2018), организационно-распорядительные документы (ГОСТ Р
7.0.97-2025), текстовые документы ЕСКД (ГОСТ Р 2.105-2019), библиографию
(ГОСТ Р 7.0.5, 7.0.100, 7.0.108), единицы величин (ГОСТ 8.417-2024),
презентацию на защите.

## Установка

```bash
# для одного проекта
git clone https://github.com/cyclomethane/gost-skills.git
mkdir -p .agents/skills
cp -r gost-skills/skills/gost .agents/skills/gost

# или глобально, для всех проектов
cp -r gost-skills/skills/gost ~/.agents/skills/gost
```

## Как пользоваться

Просто попроси: «оформи диссертацию по ГОСТ», «проверь эту ВКР», «собери
список литературы по 7.0.100». Скилл сам определит тип документа и профиль
вёрстки; в ответ на общий запрос — короткие рекомендации, полный отчёт с
номерами пунктов — по запросу детального аудита.

Для готового DOCX есть приёмочный скрипт — механическая проверка полей,
кегля, заголовков (в т. ч. подмены шрифта на Calibri), формул, таблиц,
автособираемого оглавления и метаданных пакета:

```bash
python skills/gost/scripts/gost_acceptance.py Работа.docx --profile B --type vkr
```

Устройство скилла, приоритет требований и порядок аудита — в
[`skills/gost/SKILL.md`](skills/gost/SKILL.md); правила вёрстки — в
[`layout-core.md`](skills/gost/references/layout-core.md); обязательный
состав и объём — в
[`mandatory-core.md`](skills/gost/references/mandatory-core.md).

## Приоритет требований

Требования вуза, кафедры, совета или редакции сильнее действующего ГОСТ, а
ГОСТ сильнее интерпретации скилла. Требование без проверенного источника
никогда не объявляется обязательным — только `NEEDS_SOURCE_CHECK`.
