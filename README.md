# gost-skills — скиллы ИИ-агентов для оформления и приёмки документов по ГОСТ

Набор из двух скиллов для ИИ-агентов (ZCode, Claude Code и любые ассистенты,
читающие `.agents/skills/`): собрать документ по стандарту или принять готовый
документ отчётом, в котором каждое замечание имеет ссылку на пункт ГОСТ или
методички.

| Скилл | Покрывает |
| --- | --- |
| [`skills/gost`](skills/gost/) | ВКР и дипломы, отчёты о НИР (ГОСТ 7.32-2017), журнальные статьи (ГОСТ Р 7.0.7-2021), рефераты и аннотации (ГОСТ Р 7.0.99-2018), организационно-распорядительные документы (ГОСТ Р 7.0.97-2025), текстовые документы ЕСКД (ГОСТ Р 2.105-2019), библиография (ГОСТ Р 7.0.5-2008, 7.0.100-2018, 7.0.108-2022), единицы величин (ГОСТ 8.417-2024), презентация и доклад на защите |
| [`skills/gost-dissertation`](skills/gost-dissertation/) | Диссертации и авторефераты по ГОСТ Р 7.0.11-2011: структура, титульный лист, оглавление, введение, оформление, формулы, приложения + приёмочный скрипт `gost_acceptance.py` |

## Установка

Скопируй нужную папку скилла в каталог скиллов агента:

```bash
# для одного проекта
git clone https://github.com/cyclomethane/gost-skills.git
mkdir -p .agents/skills
cp -r gost-skills/skills/gost .agents/skills/gost
cp -r gost-skills/skills/gost-dissertation .agents/skills/gost-dissertation

# или глобально, для всех проектов
cp -r gost-skills/skills/gost ~/.agents/skills/gost
```

Каталоги обнаружения по приоритету: `<проект>/.agents/skills/`, затем
`~/.agents/skills/`. Скиллы независимы, но скилл `gost` передаёт диссертации
скиллу `gost-dissertation`, поэтому для работы с диссертациями ставятся оба.

## Как это работает

1. Ты называешь документ или даёшь файл — скилл определяет тип и подключает
   профильный модуль: для ВКР это поля 30/15/20/20 мм и номер страницы снизу,
   для диссертации 25/10/20/20 и номер сверху, и так далее.
2. Механическая проверка читает `document.xml` распакованного DOCX: поля и
   кегль в твипах и полупунктах, межстрочный интервал, колонтитулы, заголовки
   без темевой подмены шрифтов, автособираемое оглавление, подписи таблиц и
   рисунков по ГОСТ 2.105, формулы как объекты OMML, метаданные без следов
   автоматизации.
3. Содержательная проверка сверяет структуру с модулем: титульный лист,
   введение, сокращения, список литературы, приложения.
4. На выходе — отчёт со статусами PASS / FAIL / N/A / NEEDS_SOURCE_CHECK и
   трассировкой к пунктам стандарта. Примеры запросов: «проверь эту ВКР по
   ГОСТ», «собери аннотацию к статье по 7.0.7», «проверь список литературы по
   7.0.100».

Диссертационный скилл дополнительно включает
[`scripts/gost_acceptance.py`](skills/gost-dissertation/scripts/gost_acceptance.py)
— механическую приёмку готового DOCX по 20 группам проверок, от полей и кегля
до геометрии формульных строк.

## Приоритет требований и границы

1. Требования вуза, кафедры, диссертационного совета или редакции.
2. Действующие национальные стандарты в пределах области применения.
3. Модули как нормализованная рабочая интерпретация стандартов.

Расхождение локальной методички со стандартом фиксируется в отчёте с обеими
ссылками. Модули не заменяют тексты стандартов: официальные карточки на
protect.gost.ru указаны в шапках модулей, действие редакций сверяется по
указателю «Национальные стандарты» на текущий год; непроверенное требование
помечается NEEDS_SOURCE_CHECK. Скиллы не строят документы и не экспортируют
PDF без явной команды; любая математика в DOCX ведётся объектами OMML, не
картинками.

## Статус

Версия модулей — 2026-09-16. Скилл `gost` сознательно не дублирует чек-листы
`gost-dissertation`: диссертационная тема живёт в нём одном. Типы документов
без модуля (курсовая, отчёт по практике, тезисы) не выдумывают требования —
для них нужен источник, методичка или стандарт.
