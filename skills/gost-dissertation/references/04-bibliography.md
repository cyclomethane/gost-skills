# Часть IV. Библиографические ссылки и список литературы

Содержание справочных приложений А и Б ГОСТ Р 7.0.11-2011. Ссылки оформляют по
ГОСТ Р 7.0.5, записи списка литературы — по ГОСТ 7.1 и ГОСТ 7.80. Примеры
воспроизводят редакцию 2011 года; актуальный статус обоих стандартов проверяй
отдельно — см. `05-standard-reference.md`.

## 1. Правила и примеры библиографических ссылок — приложение А

### 1.1 Внутритекстовые ссылки

Внутритекстовые библиографические ссылки заключают в круглые скобки.
Предписанный знак «точка и тире», разделяющий области библиографического
описания, заменяют точкой.

```
(Мунин А. Н. Деловое общение : курс лекций. М. : Флинта, 2008. 374 с.)
```

Ссылка на цитату:

```
(Мунин А. Н. Деловое общение : курс лекций. М. : Флинта, 2008. С. 50)
```

Ссылка на статью из периодического издания:

```
(Самохина М. М. Интернет и аудитория современной библиотеки //
Библиография. 2004. № 4. С. 67-71)
```

### 1.2 Повторная ссылка

Повторную ссылку на один и тот же документ или его часть приводят в сокращенной
форме при условии, что все необходимые библиографические сведения для поиска
документа указаны в первичной ссылке.

Первичная:

```
(Иванов А. И. Основы маркетинга. М., 2004)
```

Повторная:

```
(Иванов А. И. Основы маркетинга. С. 50)
```

При последовательном расположении первичной и повторной ссылок текст повторной
ссылки заменяют словами «Там же»:

```
(Иванов А. И. Основы маркетинга. М., 2004)
(Там же)
```

При ссылке на другую страницу:

```
(Иванов А. И. Основы маркетинга. М., 2004. С. 45)
(Там же, с. 54)
```

### 1.3 Подстрочные ссылки

Подстрочные библиографические ссылки оформляют как примечания, вынесенные из
текста вниз страницы.

В тексте:

```
«В. И. Тарасова в своей работе «Политическая история Латинской Америки»¹
говорит…»
```

В ссылке:

```
1 Тарасова В. И. Политическая история Латинской Америки. М., 2006. С. 34.
```

### 1.4 Подстрочная ссылка на статью из периодического издания

При наличии в тексте библиографических сведений о статье допускается в
подстрочной ссылке указывать только сведения об источнике ее публикации.

В тексте:

```
Я. Л. Шрайберг и А. И. Земсков в своей статье «Авторское право и открытый
доступ. Достоинства и недостатки модели открытого доступа»¹ указывают …
```

В ссылке:

```
1 Научные и технические библиотеки. 2008. № 6. С. 31-41.
```

### 1.5 Ссылка на электронный ресурс

При наличии в тексте библиографических сведений об электронной публикации
допускается в подстрочной ссылке указывать только ее электронный адрес.

В тексте:

```
Официальные периодические издания : электрон. путеводитель⁴.
```

В ссылке:

```
4 URL: http://www.nlr/ru/lawcenter/izd/index.html
```

### 1.6 Затекстовые ссылки

Затекстовые библиографические ссылки оформляют как перечень библиографических
записей, помещенных после текста или его составной части.

В тексте:

```
В своей монографии «Модернизм : Искусство первой половины ХХ века»,
изданной в 2003 году, М. Ю. Герман писал…¹
```

В затекстовой ссылке:

```
1 Герман М. Ю. Модернизм : Искусство первой половины ХХ века.
СПб. : Азбука-классика, 2003. 480 с.
```

Если перечень затекстовых ссылок пронумерован, номер ссылки для связи с текстом
допускается указывать в верхней части шрифта.

В тексте:

```
Данные этого исследования приведены в работе Смирнова А. А.¹
```

В затекстовой ссылке:

```
1 Смирнов А. А. Маркетинговые исследования. М. : Мысль, 2000. 220 с.
```

Допускается отсылка в квадратных скобках в строку с текстом:

```
данные этого исследования приведены в работе Смирнова А. А. [54]
```

В затекстовой ссылке:

```
Смирнов А. А. Маркетинговые исследования. М. : Мысль, 2000. 220 с.
```

Если ссылка относится к конкретному фрагменту текста, в отсылке указывают номер
и страницу: `[10, с. 96]`. Затекстовая ссылка:

```
Бердяев Н. А. Смысл истории. М. : Мысль, 1990, 173 с.
```

Если перечень затекстовых ссылок не пронумерован, в квадратных скобках указывают
фамилии авторов или название документа:

```
Этот вопрос рассматривался некоторыми авторами [Михайловым С. А., Тепляковой С. А.]
```

В затекстовой ссылке:

```
Михайлов С. А., Теплякова С. А. Периодическая печать Норвегии. СПб., 2001. 205 с.
```
