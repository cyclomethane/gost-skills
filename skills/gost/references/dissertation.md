# Диссертация и автореферат по ГОСТ Р 7.0.11-2011

Диссертацию представляют в виде рукописи, научного доклада или изданной
монографии. Рукопись допускается и для кандидатской, и для докторской степени;
научный доклад — только для докторской, на основе совокупности опубликованных
работ. Монографию стандарт не регулирует. Автореферат сопровождает диссертацию,
представленную в виде рукописи или монографии.

## Порядок работы

1. Определи форму документа: рукопись, научный доклад или автореферат.
2. Прочитай соответствующий reference-файл, `mandatory-core.md` и
   `layout-core.md`.
3. Проверь обязательные элементы и объём — первый раздел отчёта.
4. Проведи механическую проверку того, что проверяется по файлу документа.
5. Проведи содержательную проверку структуры и текста.
6. Выдай отчёт по формату раздела 21 файла `dissertation/06-checklist.md`.

## Шаг 1. Форма документа и что читать

| Форма или задача | Что читать |
| --- | --- |
| Диссертация в виде рукописи | `dissertation/01-manuscript.md` |
| Диссертация в виде научного доклада | `dissertation/02-scientific-report.md` |
| Автореферат | `dissertation/03-avtoreferat.md` |
| Библиографические ссылки и записи списка литературы | `dissertation/04-bibliography.md` |
| Область применения, определения, статус ссылочных стандартов, трассировка | `dissertation/05-standard-reference.md` |
| Формулы: строки нумерации, OMML, реестр исходников, проверка геометрии | `dissertation/07-formulas.md` |
| Машинный чек-лист и формат отчёта | `dissertation/06-checklist.md` |

Reference-файлы сохраняют содержание загруженной редакции ГОСТ Р 7.0.11-2011 и
номера исходных пунктов. Чек-лист построен для рукописи; для доклада и
автореферата бери из него статусы и формат отчёта, а требования сверяй с файлом
02 или 03.

## Шаг 2. Механическая проверка DOCX

Проверка читает файл документа и не изменяет его. Для собранного документа
запускай приёмочный скрипт:

```
python scripts/gost_acceptance.py Документ.docx --profile A --type dissertation
```

Скрипт проверяет по `document.xml` и `styles.xml`: обязательные структурные
элементы и объём, формат листа и поля, гарнитуру и кегль, межстрочный интервал,
колонтитул с номером страницы, заголовки структурных элементов, шрифты заголовков
без темевой подмены, начало глав с новой страницы, подписи рисунков и таблиц,
вёрстку подписей по ГОСТ 2.105, отсутствие табуляторов и пустых распорок после
таблиц, нумерацию и правое положение номеров формул, объекты OMML,
автособираемое оглавление, отдельную страницу содержания, символы пояснений
«где» и обозначения с индексами объектами OMML, геометрию формульной строки,
метаданные пакета. Каждый пункт помечен GATE или INFO; нарушение любого GATE
означает отказ в приёмке.

Для произвольного DOCX подключай скилл `docx`, распакуй пакет и сверь значения с
таблицами профиля А в `layout-core.md`. Твип — 1/1440 дюйма; кегль в `w:sz`
хранится в полупунктах.

Специфика профиля А, которой нет у других типов документов: номер страницы
посередине **верхнего** поля (5.3.8); заголовок отделён от текста сверху и снизу
тремя интервалами (5.3.5); белая бумага одного сорта и твёрдый переплёт (5.3.6);
титульный лист отдельной страницей с вёрсткой по центру и справа по образцу, а не
сплошным левым текстом (5.1.1). Сознательные расхождения выверенной сборки —
`layout-core.md`, раздел 15.

## Шаг 3. Содержательная проверка

Проверяй чтением документа и сверкой с reference-файлом:

- титульный лист: восемь обязательных сведений, п. 5.1.2;
- оглавление: заголовки повторяют заголовки текста дословно, отточие до номера
  страницы, п. 5.2.3;
- введение: восемь структурных элементов от актуальности до апробации, п. 5.3.1;
- деление текста и заголовки: нумерация арабскими цифрами, глава с новой
  страницы, заголовок по центру без точки и без переносов, три интервала сверху и
  снизу, пп. 5.3.2, 5.3.4, 5.3.5;
- сокращения и термины: перечень после основного текста, расшифровка при первом
  упоминании сохраняется при наличии перечня, пп. 5.4, 5.5;
- список литературы: одна группировка из трёх допустимых, иностранный ряд после
  русского, пп. 5.6.3–5.6.7;
- иллюстрации, таблицы, формулы: ссылка в тексте на каждую позицию, размещение
  после первой ссылки, пп. 5.3.9–5.3.11;
- приложения: ссылки на все приложения, порядок по ссылкам, отражение в
  оглавлении, пп. 5.7.3, 5.7.4.

Факультативные элементы — список сокращений, словарь терминов, список
иллюстративного материала, приложения — отмечай в отчёте отдельно и не считай их
отсутствие нарушением.

## Ссылочные стандарты

Библиографические ссылки оформляют по ГОСТ Р 7.0.5, записи списка литературы — по
ГОСТ 7.1 и ГОСТ 7.80, сокращения — по ГОСТ 7.11 и ГОСТ 7.12, текстовые документы —
по ГОСТ 2.105, выходные сведения — по ГОСТ Р 7.0.4, список терминов — по
ГОСТ Р 1.5. Перед записью статуса сверяй действие ссылочного стандарта по
указателю «Национальные стандарты» на текущий год; если стандарт заменён,
применяй заменяющий. Пока статус не проверен, ставь NEEDS_SOURCE_CHECK и не
объявляй требование действующим. Полный перечень со сведениями о стандарте — в
`dissertation/05-standard-reference.md`.

## Границы

Требования конкретного диссертационного совета при расхождении со стандартом
сильнее ГОСТ; такие расхождения фиксируй в отчёте с обеими ссылками. Оформление
диссертации в виде изданной монографии стандартом не покрыто. Примеры записей из
приложений А и Б воспроизводят редакцию 2011 года и служат образцами формы, а не
проверкой актуального статуса самих стандартизированных форматов.
