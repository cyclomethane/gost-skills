# ГОСТ Р 7.0.99-2018: реферат и аннотация

## 0. Назначение этого SKILL

Этот файл преобразует требования ГОСТ Р 7.0.99-2018 в рабочий регламент для подготовки и проверки рефератов и аннотаций. Требования стандарта сохранены, а материал перегруппирован по практическим задачам: сначала определяется тип вторичного документа, затем проверяются обязательные смысловые элементы, стиль, объём, оформление и соответствие первоисточнику.

При использовании SKILL:

1. Определи, требуется **реферат** или **аннотация**.
2. Для реферата определи режим: информативный, индикативный или информативно-индикативный.
3. Для аннотации при необходимости определи разновидность: справочная, рекомендательная, общая, специализированная, аналитическая, краткая, развёрнутая, издательская, библиографическая.
4. Работай только с информацией, поддерживаемой исходным документом, кроме специально разрешённых стандартом дополнительных сведений.
5. Для научного или экспериментального документа по умолчанию отдавай приоритет **информативному реферату**, поскольку стандарт рекомендует его для документов, посвящённых одной теме, и экспериментальных работ.
6. Сохраняй трассировку замечаний к конкретным пунктам ГОСТ.
7. Для ссылочных стандартов учитывай требование источника проверять их действующий статус на момент применения.
8. При подготовке аннотации к журнальной статье дополнительно применяй ГОСТ Р 7.0.7-2021: он ограничивает объём аннотации статьи 250 словами и задаёт требования к издательскому оформлению.

# Часть I. Область применения, определения и выбор режима

## 1. Область применения — исходный раздел 1

Стандарт устанавливает требования к:

- содержанию реферата и аннотации;
- построению текста;
- оформлению текста.

Стандарт предназначен для физических лиц и организаций, подготавливающих и выпускающих первичные и вторичные документы, включая электронные документы.

Стандарт рекомендован авторам:

- научно-технических документов;
- научно-практических документов;
- статей;
- текстов докладов;
- монографий;
- авторских резюме/рефератов к собственным публикациям;
- аннотаций к книгам, монографиям, учебным пособиям и другим изданиям.

## 2. Основные определения — исходный раздел 3

### 2.1 Реферат — 3.1

**Реферат** — краткое точное изложение содержания первичного документа в текстовой форме, включающее основные фактические сведения и выводы без дополнительной интерпретации и критических замечаний автора реферата.

### 2.2 Виды реферата по форме изложения — 3.1.1-3.1.3

**Информативный реферат** — отражает в обобщённом виде все основные положения первичного документа.

**Индикативный реферат** — кратко отражает основные темы и вид первичного документа.

**Информативно-индикативный реферат** — комбинированный вариант, отражающий в сокращённом виде основные положения и аспекты первичного документа.

### 2.3 Виды реферата по числу источников — 3.1.4-3.1.5

- **монографический** — составлен по одному первичному документу;
- **сводный (обзорный)** — составлен по двум и более первичным документам.

### 2.4 Виды реферата по читательскому назначению — 3.1.6-3.1.7

- **общий** — ориентирован на широкую аудиторию;
- **специализированный** — ориентирован на специалистов.

### 2.5 Виды реферата по составителю — 3.1.8-3.1.10

- **авторский реферат / автореферат** — составлен автором первичного документа;
- **неавторский реферат** — составлен референтом;
- **машинный / автоматический реферат** — составлен с использованием компьютерной программы.

Примечание источника: автореферат диссертации регулируется ГОСТ Р 7.0.11.

### 2.6 Аннотация — 3.2

**Аннотация** — краткая характеристика первичного документа с точки зрения его назначения, содержания, вида, формы и других особенностей.

### 2.7 Виды аннотаций — 3.2.1-3.2.9

Трассировка внутри группы: справочная — 3.2.1; рекомендательная — 3.2.2; общая — 3.2.3; специализированная — 3.2.4; аналитическая — 3.2.5; краткая — 3.2.6; развёрнутая — 3.2.7; издательская — 3.2.8; библиографическая — 3.2.9.

По содержанию и целевому назначению:

- **справочная** — характеризует тематику и даёт уточняющие сведения без критической оценки и рекомендаций; может быть описательной или информационной;
- **рекомендательная** — характеризует первоисточник и содержит рекомендации по его использованию.

По полноте охвата и читательскому назначению:

- **общая** — характеризует документ в целом для широкого круга пользователей;
- **специализированная** — характеризует документ в определённых аспектах для узкого круга специалистов;
- **аналитическая** — составляется по наиболее актуальным тематическим разделам, главам или параграфам, а не по документу целиком.

По объёму:

- **краткая** — характеризует один аспект первоисточника;
- **развёрнутая** — содержит короткий пересказ содержания и перечисление разделов/рубрик; типична для научных работ, учебников и монографий.

По области применения:

- **издательская** — кратко характеризует издание по целевому назначению, содержанию, читательскому адресу, издательско-полиграфической форме и другим особенностям;
- **библиографическая** — входит в библиографическую запись и содержит сведения о целевом назначении, читательском адресе, авторе, жанре, времени создания и печати произведения.

## 3. Быстрый выбор типа документа

### 3.1 Когда использовать информативный реферат — 4.4

Используй его для:

- документа по одной теме;
- экспериментальной работы;
- научной работы, где важны фактические результаты, метод и выводы.

Он должен передавать основную фактографическую информацию первичного документа.

### 3.2 Когда использовать индикативный реферат — 4.5

Используй его преимущественно для:

- политематических обзоров;
- сборников;
- монографий;
- случаев, когда задача состоит в быстром понимании тематики и целесообразности обращения к полному тексту.

Он отражает основные аспекты содержания без детального фактографического изложения.

### 3.3 Когда использовать информативно-индикативный реферат — 4.6

Используй при ограничении объёма, когда требуется совместить передачу основных результатов и краткое обозначение остальных аспектов документа.

### 3.4 Когда использовать аннотацию

Используй аннотацию, когда требуется характеристика документа, его назначения, содержания, новизны, достоинств, научного/практического значения и читательской аудитории, а не подробная передача фактографии исследования.

# Часть II. Общие принципы реферата и аннотации

## 4. Различие реферата и аннотации — исходный пункт 4.1

При аналитико-синтетической переработке первичного документа информацию отбирают качественно и представляют в сжатой форме.

- **Аннотация** сообщает сведения о первоисточнике.
- **Реферат** передаёт основное содержание первоисточника.

## 5. Функции реферата — 4.2-4.3

Реферат должен позволять:

1. установить основное содержание документа;
2. определить релевантность документа;
3. принять решение о целесообразности обращения к полному тексту;
4. получить сведения о документе без чтения полного текста, если документ представляет второстепенный интерес;
5. использовать основные термины и ключевые слова для автоматизированного поиска;
6. применять текст в информационных системах для поиска документов и информации.

Реферат может выступать элементом библиографической записи и выходных сведений.

# Часть III. Реферат

## 6. Смысловая структура информативного реферата — 4.4 и 5.1.1

Информативный реферат может включать:

1. предмет, тему и цель работы;
2. метод или методологию проведения работы;
3. результаты работы;
4. область применения результатов;
5. выводы;
6. дополнительную информацию.

Оптимальная последовательность зависит от назначения реферата. Для пользователя, ориентированного на новые научные знания, стандарт рекомендует делать акцент на результатах и выводах.

## 7. Смысловая структура индикативного реферата — 4.5 и 5.1.1

Индикативный реферат включает:

1. вид и форму документа;
2. предмет и тему работы;
3. результаты работы;
4. область применения результатов;
5. выводы.

Он предназначен прежде всего для указания на аспекты содержания и помощи читателю в решении, следует ли обращаться к первичному документу.

## 8. Что включать в отдельные смысловые элементы — 5.1.2-5.1.8

### 8.1 Предмет, тема и цель — 5.1.2

Указывай их, если они недостаточно ясны из заглавия документа.

### 8.2 Метод или методология — 5.1.3

Развёрнуто описывай метод, когда он:

- обладает новизной;
- представляет самостоятельный интерес для работы.

Широко известные методы достаточно перечислить.

Для неэкспериментальных работ указывай используемые данные и характер их обработки.

### 8.3 Результаты — 5.1.4

Приоритетно отражай:

- основные теоретические результаты;
- основные экспериментальные результаты;
- фактические данные;
- выявленные взаимосвязи;
- выявленные закономерности;
- новые результаты;
- данные долгосрочного значения;
- важные открытия;
- результаты, имеющие практическое значение по оценке автора исходного документа.

Выводы, противоречащие существующим теориям, также относятся к приоритетно отражаемой информации, если они присутствуют в исходном документе.

### 8.4 Область применения — 5.1.5

Указывай область применения результатов прежде всего для:

- патентных документов;
- документов практической направленности.

### 8.5 Выводы — 5.1.6

Выводы могут сопровождаться:

- рекомендациями;
- оценками;
- предложениями;
- гипотезами.

Условие: эти положения должны присутствовать в исходном документе.

### 8.6 Дополнительная информация — 5.1.7

Допускается включать сведения, второстепенные относительно основной цели исследования, но значимые вне основной темы, включая:

- организацию, где выполнена работа;
- сведения об авторе исходного документа;
- количество иллюстраций;
- количество таблиц;
- количество библиографических ссылок.

### 8.7 Электронные документы — 5.1.8

Допускается приводить сведения:

- об информационной оболочке;
- о функциональных свойствах объектов;
- о печатном аналоге;
- об аудиовизуальной продукции, использованной в основе или составе электронного документа/издания.

## 9. Требования к содержанию и стилю реферата — 5.2.1-5.2.12

### 9.1 Только сведения исходного документа — 5.2.1

Текст реферата формируют из содержания исходного документа. Собственная интерпретация референта, его критические замечания и его точка зрения исключаются.

Критические замечания могут быть заимствованы из опубликованных источников при соответствующей ссылке.

### 9.2 Лаконичность — 5.2.2

Текст должен характеризоваться:

- лаконичностью;
- чёткостью;
- убедительностью формулировок;
- отсутствием второстепенной информации.

### 9.3 Начало текста — 5.2.3

Первую фразу формулируй так, чтобы она сразу выражала главную тему документа.

Текст реферата не должен механически повторять сведения, уже содержащиеся в заглавии и библиографическом описании.

Убирай лишние вводные формулы вида «автор статьи рассматривает...», когда без них смысл сохраняется.

Исторические справки, обзор ранее опубликованных работ и общеизвестные положения включай только тогда, когда они составляют основное содержание исходного документа.

### 9.4 Синтаксис — 5.2.4

Используй синтаксические конструкции, характерные для научных и технических документов. Сохраняй ясность и избегай неоправданно сложных грамматических конструкций.

### 9.5 Терминология — 5.2.5-5.2.6

- применяй стандартизованную терминологию;
- в общественных науках допускается терминология исходного документа;
- используй значимые слова из первичного документа, чтобы поддержать автоматизированный поиск.

### 9.6 Сокращения и условные обозначения — 5.2.7

Общеупотребительные сокращения допустимы.

Редкие сокращения и условные обозначения применяй только при необходимости и раскрывай при первом употреблении.

### 9.7 Единицы величин — 5.2.8

Физические величины приводи в международной системе СИ. Рядом в круглых скобках допускается значение в системе единиц исходного документа.

### 9.8 Имена собственные — 5.2.9

Фамилии, наименования организаций, изделий и другие собственные имена приводи на языке первоисточника.

### 9.9 Географические названия — 5.2.10

Приводи географические названия в нормативной форме, предусмотренной источником стандарта.

### 9.10 Таблицы, формулы и графика — 5.2.11

Включай таблицы, формулы, чертежи, рисунки, схемы и диаграммы только при необходимости, когда они:

- раскрывают основное содержание документа;
- позволяют сократить объём реферата.

Повторяющиеся формулы могут иметь собственную порядковую нумерацию; она может отличаться от нумерации оригинала.

### 9.11 Объём — 5.2.12

Объём определяется:

- количеством существенных сведений;
- их научной ценностью;
- их практическим значением;
- доступностью документа;
- языком реферируемого документа.

**Рекомендуемый средний объём текста реферата — 850 печатных знаков.**

Это рекомендация среднего объёма стандарта, а не абсолютный предел для любого вида документа.

## 10. Оформление и расположение реферата — 5.3.1-5.3.6

### 10.1 Место публикации — 5.3.1

Реферат может:

- публиковаться вместе с реферируемым документом;
- входить в библиографическую запись документа.

### 10.2 Заглавие — 5.3.2

Если реферат составлен на языке оригинала, его заглавие обычно совпадает с заглавием первичного документа.

Заглавие может отличаться, когда:

- реферат составлен на другом языке;
- реферируется только часть документа;
- заглавие исходного документа не отражает его содержания;
- составляется сводный реферат на несколько документов.

### 10.3 Положение в информационном издании — 5.3.3

Текст реферата размещают после библиографического описания реферируемого документа.

Для сводного реферата допускается размещение текста между заглавием реферата и библиографическим описанием реферируемых документов.

### 10.4 Ссылки — 5.3.4

Ссылки размещают:

- в тексте реферата в круглых скобках после соответствующей фразы; или
- в конце реферата.

### 10.5 Издательское оформление — 5.3.5

Для реферата, публикуемого в издании, применяются соответствующие правила издательского оформления, на которые ссылается исходный ГОСТ.

### 10.6 Реферат в отчёте о НИР — 5.3.6

Структуру и оформление реферата в отчёте о научно-исследовательской работе проверяют по применимому стандарту на отчёт о НИР.

# Часть IV. Аннотация

## 11. Содержание аннотации — 4.7 и 6.1-6.3

Аннотация может содержать сведения:

- о содержании документа;
- об авторе;
- о типе документа;
- об основной теме;
- о проблемах;
- об объекте;
- о цели работы;
- о результатах;
- о новизне;
- о достоинствах;
- о научном значении;
- о практическом значении для целевой аудитории;
- о читательском адресе;
- о целевом назначении.

При переиздании может указываться:

- изменение заглавия;
- изменение авторского коллектива;
- год выпуска предыдущего издания.

Для многотомного издания может указываться год начала выпуска.

Для переведённого документа может указываться принадлежность автора к стране.

В аннотацию не включай сведения, уже содержащиеся в библиографическом описании.

## 12. Дополнительные требования к аннотациям — 6.2-6.7

### 12.1 Сведения из других документов — 6.2

Аннотация может включать сведения об авторе и достоинствах произведения, заимствованные из других документов.

### 12.2 Научно-технические документы — 6.4

Для научно-технических аннотаций применяй требования 5.2.4-5.2.11:

- научно-технический синтаксис;
- стандартизованную терминологию;
- значимые поисковые слова;
- контролируемое использование сокращений;
- единицы СИ;
- корректную передачу имён и географических названий;
- включение таблиц, формул и рисунков только при необходимости.

### 12.3 Художественная литература — 6.5

Аннотация должна содержать сведения о:

- литературном жанре;
- теме произведения;
- месте действия;
- времени действия.

### 12.4 Периодические и продолжающиеся издания — 6.6

Аннотация включает данные о:

- задачах;
- целях;
- характере издания;
- объединении;
- разделении;
- возобновлении;
- прекращении выпуска;
- других изменениях издания.

### 12.5 Электронные документы и издания — 6.7

При описании электронного документа указывай при необходимости:

- информационно-технологические свойства оболочки;
- функциональные свойства;
- сведения о программной реализации представления данных.

## 13. Объём и оформление аннотации — 6.8-6.10

**Рекомендуемый средний объём аннотации — 600 печатных знаков.**

Оформление аннотации в информационном издании выполняют по правилам расположения, связанным с 5.3.3.

Издательское оформление и расположение аннотации проверяют по применимым ссылочным стандартам, указанным в источнике.

Для статьи действует дополнительное специальное ограничение ГОСТ Р 7.0.7-2021: аннотация статьи — до 250 слов.

# Часть V. Методика подготовки

## 14. Общая методика реферирования — приложение А, справочное

Реферирование понимается как аналитико-синтетическая переработка информации первичного документа, при которой отражаются основные положения, фактические данные, результаты и выводы. Результатом является вторичный документ — реферат.

### 14.1 Функции методики

- информационная;
- поисковая.

### 14.2 Пять этапов реферирования

1. **Ознакомительный** — предварительное общее знакомство с первоисточником, чтение, при необходимости работа со справочной и дополнительной литературой.
2. **Аналитический** — выделение реферативных сведений.
3. **Синтетический** — обобщение отобранных сведений и построение текста.
4. **Редакционный** — проверка текста на соответствие требованиям.
5. **Оформительский** — включение подготовленного текста в библиографическую запись или другой предусмотренный формат.

### 14.3 Три вида чтения

Трём первым этапам соответствуют:

- ознакомительное чтение;
- изучающее чтение;
- реферативное чтение.

### 14.4 Ознакомительный этап

На этом этапе устанавливают:

- актуальность темы;
- значение работы;
- представительность научных выводов;
- полезность информации;
- целесообразность реферирования.

Определяются тематическая направленность, общий смысл и информативность документа.

### 14.5 Работа со справочной литературой

Она используется для:

- устранения неясностей;
- понимания терминов;
- идентификации персоналий;
- оценки места документа среди близких публикаций;
- более точного понимания новизны и релевантности.

При подготовке авторского реферата к собственной статье дополнительный внешний материал нельзя превращать в новые утверждения реферата, отсутствующие в первичном документе.

### 14.6 Аналитический этап

Текст:

- повторно читают;
- делят на смысловые части;
- выделяют наиболее информативные фрагменты;
- исключают несущественные сведения;
- определяют способ представления материала согласно цели реферата.

### 14.7 Синтетический этап

Из отобранных сведений создают новый целостный текст. Структура реферата может отличаться от композиции первичного документа и определяется логикой связи существенных сведений.

### 14.8 Редакционный этап

Приложение А описывает реферат как цельный связный условно самостоятельный текст, оформленный одним абзацем и передающий в сжатом виде основную информацию первоисточника.

Для режима строгого следования приложению А:

- один абзац;
- без внутренних разделов;
- без рубрик;
- без дополнительного членения.

### 14.9 Оформительский этап

Методика приложения А выделяет три функциональные части:

1. **заголовочная** — библиографическое описание реферируемого документа;
2. **собственно реферативная** — текст, а при необходимости формулы, таблицы, графики, диаграммы, иллюстрации;
3. **справочная** — дополнительные сведения, например количество иллюстраций, таблиц, приложений.

## 15. Общая методика аннотирования — приложение В, справочное

Аннотирование — аналитико-синтетическая переработка первичного документа с целью получить обобщённую характеристику, раскрывающую логическую структуру, существенные стороны содержания и достоинства.

В аннотацию отбирают признаки, позволяющие:

- определить научное значение;
- определить практическое значение;
- показать новизну;
- отличить документ от близких по тематике и назначению.

### 15.1 Функции аннотации

- **сигнальная** — помогает установить содержание, релевантность и целесообразность чтения полного текста;
- **поисковая** — поддерживает автоматизированный поиск документов.

### 15.2 Пять этапов аннотирования

1. общий анализ документа и определение информативности;
2. анализ всех частей документа;
3. синтезирование свёрнутой информации;
4. редактирование текста;
5. запись и оформление аннотации.

## 25. Формат отчёта SKILL

При проверке документа выдавай:

1. **Тип документа** — реферат или аннотация; выбранная разновидность.
2. **Критические несоответствия** — добавленные факты, искажение результатов, отсутствие ключевых результатов или выводов.
3. **Структурные несоответствия** — пропущенные обязательные смысловые элементы выбранного типа.
4. **Стилевые несоответствия** — избыточность, вводные формулы, терминологическая непоследовательность, неоправданно сложный синтаксис.
5. **Формальные несоответствия** — объём, сокращения, единицы, оформление ссылок и расположение текста.
6. **Трассировка** — для каждого замечания указывай пункт ГОСТ Р 7.0.99-2018.
7. **Итоговый статус** — `PASS`, `PASS_WITH_REMARKS`, `FAIL`.
