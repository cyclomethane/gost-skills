# SKILL: ГОСТ Р 7.0.5-2008 — библиографические ссылки

Версия SKILL: 2026-09-16  
Нормативная основа: **ГОСТ Р 7.0.5-2008 «СИБИД. Библиографическая ссылка. Общие требования и правила составления»**. Стандарт действует.

Официальная карточка: https://protect.gost.ru/gost/details/2eef7820-44bc-49a4-bf1f-fe51c54039dc


## Режим применения

Этот файл предназначен для использования как operational SKILL: при подготовке, редактировании и аудите университетских документов агент должен применять правила последовательно и сохранять трассировку к соответствующему стандарту.

Приоритет требований:
1. Прямые требования образовательной организации, кафедры, программы ГИА, журнала или редакции для конкретного документа.
2. Действующие национальные и межгосударственные стандарты в пределах их области применения.
3. Настоящий SKILL как нормализованная рабочая интерпретация стандартов.
4. Общие редакционные рекомендации применяются только в областях, где пункты 1–3 оставляют выбор.

При конфликте требований фиксировать источник более высокого приоритета и применять его. Конкретные локальные шаблоны сохранять без самовольной перестройки.

## Статусы правил

- **MUST** — прямое требование стандарта или обязательное следствие его нормы.
- **SHOULD** — рекомендация стандарта или безопасная университетская практика.
- **MAY** — допустимый вариант.
- **LOCAL** — параметр задаётся локальным регламентом организации.

## Общая процедура аудита

1. Определить тип документа и область применения стандарта.
2. Проверить актуальность редакции стандарта и поправок.
3. Зафиксировать локальные требования вуза/кафедры.
4. Проверить структуру документа.
5. Проверить реквизиты и метаданные.
6. Проверить основной текст, нумерацию и перекрёстные ссылки.
7. Проверить таблицы, рисунки, формулы и приложения.
8. Проверить библиографический аппарат.
9. Проверить техническую воспроизводимость: поля, шрифты, переносы, номера страниц, работа ссылок.
10. Сформировать перечень дефектов с указанием источника требования и приоритета исправления.


## 1. Назначение

SKILL используется для оформления связей между утверждениями текста и источниками: цитатами, пересказами, заимствованными данными, таблицами, рисунками, нормативными документами и архивными материалами.

Стандарт регулирует **библиографическую ссылку**. Для полного библиографического описания записи дополнительно применяется ГОСТ Р 7.0.100-2018; для сетевых электронных документов — ГОСТ Р 7.0.108-2022.

## 2. Что должна обеспечивать ссылка

Ссылка должна содержать сведения, достаточные для:
- идентификации источника;
- поиска источника;
- связи конкретного утверждения с объектом ссылки;
- различения источников с близкими заглавиями или авторами.

## 3. Виды ссылок по полноте

### Полная ссылка

Используется, когда ссылка сама должна давать развёрнутую характеристику источника.

### Краткая ссылка

Используется, когда задача состоит в идентификации и поиске, а полные сведения уже находятся в другом элементе документа, например в затекстовом перечне.

## 4. Виды ссылок по расположению

ГОСТ выделяет:
- внутритекстовые;
- подстрочные;
- затекстовые.

Формат должен быть единообразен в рамках всего документа.

## 5. Первичные и повторные ссылки

Первая ссылка на объект может содержать расширенные сведения. Повторная ссылка допускает сокращённую форму, если объект однозначно идентифицируется.

Контроль:
- повторная ссылка должна однозначно указывать на первоначальный объект;
- сокращение не должно создавать коллизий между источниками;
- локальная методичка может требовать каждый раз использовать номер затекстовой записи.

## 6. Комплексные ссылки

Несколько источников могут объединяться в одну комплексную ссылку. Порядок их перечисления должен иметь понятный принцип: хронология, алфавит, логика аргумента либо порядок нумерации списка.

## 7. Внутритекстовая ссылка

Внутритекстовая ссылка помещается непосредственно внутри текста и заключается в круглые скобки. Она содержит сведения, которых достаточно для идентификации объекта в данном контексте.

Применять этот вариант только при соответствии локальному стилю. Для диссертаций и технических ВКР чаще удобнее затекстовая нумерованная система.

## 8. Подстрочная ссылка

Подстрочная ссылка оформляется как примечание внизу страницы и связывается с текстом знаком сноски.

Проверять:
- единый порядок нумерации;
- связь с конкретным фрагментом;
- отсутствие разрыва между номером сноски и самой записью;
- достаточность сведений;
- корректность повторных ссылок.

## 9. Затекстовая ссылка

Совокупность затекстовых ссылок располагается после текста документа или его части. Для связи с записью применяются номера либо иные идентифицирующие отсылки.

Для нумерованного университетского текста рабочий формат:
- в тексте: `[12]`;
- при указании конкретного фрагмента: `[12, с. 47]`;
- несколько источников: формат задаётся локальным регламентом, например `[3, 7, 12]` или диапазон.

**MUST:** сохранять единый формат во всей работе.

## 10. Связь отсылки и затекстовой записи

Если записи нумеруются, номер записи становится основным идентификатором отсылки. Стандарт допускает квадратные скобки для таких отсылок.

Для ссылки на конкретную страницу указываются номер записи и страница. Это особенно важно при прямой цитате.

## 11. Автор–год

При ненумерованном затекстовом перечне допускаются отсылки по автору/заглавию с добавлением года и страницы при необходимости. Применять только при согласовании с локальным стилем.

## 12. Цитирование через вторичный источник

Когда исходный текст доступен только через другую публикацию, ссылка должна явно показывать посредника. Стандарт предусматривает формулы типа `Цит. по:`. Научная работа должна по возможности обращаться к первоисточнику; использование вторичного источника фиксируется честно.

## 13. Ссылка на конкретный фрагмент

Для прямой цитаты, определения, численного значения или точного положения рекомендуется указывать страницу, диапазон страниц, пункт, параграф, статью нормативного акта или иной локатор.

## 14. Ссылки на электронные ресурсы

ГОСТ Р 7.0.5 содержит базовые правила, а для современных сетевых документов применять ГОСТ Р 7.0.108-2022. Сетевой источник должен иметь URL и дату обращения в предусмотренных случаях; DOI предпочтителен как устойчивый идентификатор для научных публикаций.

## 15. Ссылки на стандарты

При ссылке на стандарт идентификатор стандарта должен быть точным. Для актуального документа проверять:
- обозначение;
- год;
- заглавие;
- статус;
- дату обращения к электронной версии при использовании сети.

## 16. Ссылки на нормативные правовые акты

Состав сведений определяется типом акта и локальным регламентом. Минимальный набор должен позволять однозначно определить документ, дату, номер и источник официального опубликования либо официальный сетевой ресурс.

## 17. Ссылки на архивные документы

ГОСТ Р 7.0.5 содержит специальные правила для архивных документов. Проверять:
- название архива;
- фонд;
- опись;
- дело;
- лист/листы;
- дополнительные идентификаторы архива.

## 18. Сокращения

Сокращения в библиографических сведениях должны следовать профильным стандартам. Основное заглавие ресурса сохраняется в полной форме. Для русского текста ориентироваться на действующий ГОСТ Р 7.0.12-2011.

## 19. Практическое правило для диссертации/ВКР

Если локальная методичка использует нумерованные затекстовые ссылки, применять следующую процедуру:
1. присвоить каждой записи стабильный номер;
2. вставлять номера через автоматический механизм либо менеджер библиографии;
3. для точных цитат добавлять страницу;
4. перед финальной сдачей проверить все номера после сортировки/редактирования;
5. выявить ссылки без записей и записи без ссылок;
6. проверить DOI/URL.

## 20. Типичные дефекты

- ссылка указывает на отсутствующую запись;
- номер ссылки изменился после перестановки списка;
- прямая цитата дана без локатора;
- один источник имеет две разные записи;
- одинаковые источники записаны с разной транслитерацией автора;
- ссылка на сайт ведёт только на главную страницу вместо цитируемого документа;
- сетевой документ оформлен по устаревшей модели при наличии ГОСТ Р 7.0.108-2022;
- ссылка используется как замена объяснению авторского вывода.

## 21. Машинный чек-лист

- [ ] В работе выбран один основной тип ссылок.
- [ ] Все отсылки имеют соответствующие записи.
- [ ] Каждая запись, включённая как затекстовая ссылка, реально используется в тексте.
- [ ] Прямые цитаты имеют локатор.
- [ ] Повторные ссылки однозначны.
- [ ] Электронные источники оформлены по ГОСТ Р 7.0.108-2022.
- [ ] Библиографические описания проверены по ГОСТ Р 7.0.100-2018.
- [ ] Сокращения единообразны.
- [ ] Имена авторов и заглавия совпадают с источниками.
- [ ] DOI и URL проверены.
- [ ] Нумерация ссылок стабильна после финальной сборки.
